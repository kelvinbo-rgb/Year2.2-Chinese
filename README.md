# 二年级(下)语文小助手 (Year 2 Chinese Literacy & Reading Helper)

这是一个专为小学二年级学生设计的语文学习与课文领读网页应用 (Web App)。

## 核心功能特点

- 📖 **课文与生字一体化**：
  - 完整收录部编版（人教版）二年级下册全部课文原文（第1~24课、识字1~4及语文园地）。
  - 原文带标准注音（Ruby Pinyin 排版），生字字音精准对照。
  - 支持逐字点读：点击课文中任何汉字，立即发音并查看该字的笔顺与拼读。

- 🗣️ **永久免费“AI 领读-跟读”模式 (免额度消耗)**：
  - **零 API 消耗**：基于浏览器原生中文语音引擎，无需配置 API Key，永不产生费用与 Token 限制。
  - **领读-跟读模式（默认等待孩子手动点下一句）**：系统清晰慢速朗读一句 ➔ 提示“轮到小朋友跟读啦” ➔ 孩子跟着大声朗读完毕后，点击“我读完啦，下一句 ➡”（或按空格键）继续下一句，不催促孩子，节奏自由掌握。
  - **支持连贯朗读**：支持整篇课文逐句流畅朗读与高亮跟随。
  - **儿童慢速朗读**：提供 0.75x 慢速（咬字极清，专为跟读设计）、0.85x 及 1.0x 语速。

- 🔤 **真正会读拼音的“拼读教学引擎”**：
  - **字音标准读**：清晰单字慢速发音，彻底解决网络工具把拼音念成英文字母的痛点。
  - **声韵母拼读分解**：自动拆解**声母（呼读音，如吃、得、玻）、韵母、声调、拼读公式**。
    - 普通音节：如“春”，示范“声母 吃，韵母 ūn，拼读：吃——ūn——春！”
    - 整体认读音节：如“是、日”，明确提示“🌟 整体认读音节：不用拼，直接读！”

- ✍️ **动态笔顺与静态步进分解（照着纸上抄写神器）**：
  - **动态田字格动画**：基于 Hanzi Writer，部首标红，支持慢速演示与屏幕描红练写。
  - **静态步进笔画分解图**：在下方生成 `第1画`、`第2画`、`第3画`……当前笔画标红，历史笔画标黑。孩子把作业本放在屏幕前，抬头看着每一画，低头在纸上抄写，笔顺绝对不倒插笔。

- 🎤 **随练与孩子语音输入**：
  - 支持课外非课文内容学习，可自由输入任意句子、生词。
  - 支持**大号麦克风语音输入**：孩子点击麦克风说出词语（如“小燕子”），自动识别并生成拼音、拼读与笔顺。

- 📝 **趣味测验**：支持“本课小测验”和“综合测试”，寓教于乐。

## 如何使用

### 本地直接打开 / 本地服务
直接在浏览器中打开 `index.html` 即可使用。若需要完全加载本地汉字离线包，建议使用本地简易 HTTP 服务（如 VSCode Live Server 或 `npx serve .`）。

### GitHub Pages 部署
1. 将本项目的所有文件推送到 GitHub 仓库。
2. 在仓库的 **Settings (设置)** -> **Pages** 中，将 Source 设置为 `main` 分支的 `/ (root)`。
3. 保存后即可在手机、iPad 或电脑浏览器中直接打开使用。
