# 二年级语文生字小助手 (Year 2 Chinese Literacy Helper)

这是一个为小学二年级学生设计的生字学习网页应用 (Web App)。

## 功能特点
- 📜 **生字表**：收录了人教版（部编版）二年级上册写字表的生字。
- ✍️ **动态笔顺**：点击每个生字，可以看到标准的汉字书写笔顺动画 (基于 Hanzi Writer)。
- 🔊 **标准读音**：内置拼音注音和语音朗读功能。
- 📝 **趣味测验**：支持“本课小测验”和“综合测试”，寓教于乐。
- 📱 **平板适配**：专为 iPad 和安卓平板设计的大按钮和触控界面。

## 如何使用 (GitHub Pages)
1. 将本项目的所有文件上传到 GitHub 仓库。
2. 在仓库的 **Settings (设置)** -> **Pages** 中，将 Source 设置为 `main` 分支的 `/ (root)`。
3. 保存后，GitHub 会生成一个链接 (例如 `https://username.github.io/repo-name/`)。
4. 在平板浏览器中打开该链接即可使用，无需安装 App。

## 离线/本地开发
本项目包含离线数据包 (`libs/` 和 `data/`)，可以直接在本地搭建简单的 HTTP 服务器运行。
